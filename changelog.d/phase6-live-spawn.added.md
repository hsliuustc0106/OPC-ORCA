Live spawn of `orca` (Linux: `orca-ide`) runs only when `OPC_ORCA_LIVE=1` or the adapter `live` option is set. Dry-run stays the default and does not spawn. The live path parses stdout lines for ids and throws on a missing binary, a non-zero exit, or unparseable stdout. The coordinator still stores only dry-run plans, so that failure, and a live result, do not advance the dig loop.
