The dig loop stores a parsed live Orca result and advances on that parse. A missing binary, a non-zero exit, unparseable stdout, or any other throw does not advance state. Dry-run plans stay the default and stay free of ids. The DeepSeek Harness plugin registers a dig tool that runs the coordinator and returns a status summary. Live mode is on only when OPC_ORCA_LIVE=1 or live is true. The loop and the tool still stop at awaiting_human_pr and do not open, update, or merge a pull request.
