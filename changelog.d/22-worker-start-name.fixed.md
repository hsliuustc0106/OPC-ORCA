Live worker-start for a new-child worktree passes a unique --name. The desktop agent id comes from OPC_ORCA_AGENT or config agent and is not the product label dsh; an unset or unrecognized id throws no-agent before spawn. A non-ready receipt stays a failure and the error names failedStage and lastError without storing the dispatch id. Optional --setup is passed only when the operator sets run, skip, or inherit. Dry-run plans and awaiting_human_pr are unchanged.
